# Nervous System Regulation

Category for somatic / parasympathetic / brain-retraining interventions. Important in the context of chronic sympathetic overdrive in [[ME-CFS]] / [[Long COVID]] / [[POTS]] / [[MCAS]].

## Modalities

- Meditation, breathwork (esp. slow nasal 6/min)
- Brain / limbic retraining (DNRS, Gupta Program — not specifically detailed in source)
- EMDR
- Neurofeedback
- Vagus nerve stimulation (non-invasive devices) — TBD in source
- Yoga nidra / NSDR

## Related interventions

- [[Stellate Ganglion Block]] — pharmacological sympathetic reset
- HRV biofeedback
