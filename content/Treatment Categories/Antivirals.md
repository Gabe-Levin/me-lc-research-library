# Antivirals

Category note. Used to address [[Viral Persistence and Reactivation]] in [[ME-CFS]] / [[Long COVID]]. Choice depends on which pathogen is implicated.

## By pathogen

| Pathogen | First-line antiviral options |
|---|---|
| [[EBV]] | [[Valacyclovir]], [[Acyclovir]], [[Famciclovir]], [[Truvada]] (tenofovir) |
| [[HHV-6]] | [[Valganciclovir]], [[Valacyclovir]] |
| [[CMV]] | [[Valganciclovir]] |
| [[Enteroviruses]] | [[Oxymatrine Equilibrant]], [[Dihydroquercetin]], [[Remdesivir]], [[Paxlovid]], Ribavirin, interferon (rarely now) |
| [[SARS-CoV-2]] persistence | [[Paxlovid]], [[Remdesivir]], [[Truvada]] |
| [[Lyme Bartonella Babesia]] | doxycycline + rifampin, etc. (out of source scope) |

## Adjuncts

- IMC-2: low-dose [[Valacyclovir]] + celecoxib (Dogwood)
- High-dose IV vitamin C — observational EBV titer reduction
- Maraviroc + pravastatin (LC persistence/CD16+ monocyte targeting)
- [[Low Dose Rapamycin]] — has antiviral properties via mTOR inhibition
- [[Methylene Blue]] — broad antimicrobial/antiviral
